## UnixAgentServerによるマルチエージェントオーケストレーション
デフォルトのsub-agentは使いにくく,また再利用が困難であるので、それらを改善する新しいsub-agentの実装を提案する.

### 1Agent=1Process=1UnixAgentServer
1Agent=1Processとし、sub-agentなどに期待されるマルチエージェントオーケストレーションを,UnixDomainSocketによるプロセス間通信として実現することで,既存のものよりも柔軟で,拡張性が高く,ClaudeCodeの潜在能力を最大限発揮できるようになります。
UnixAgentServerは、ClaudeSDKClientなどを抽象化したIAgent規格のインスタンスと初期化することで,socketで対話可能な単一エージェントのプロセスを起動します。
Agentは,`Bash`でコマンドすることで他のAgentを操作できるし、UnixAgentMCPを使ってもいい。
起動したSub-agentの進捗やステータスを確認する方法はClaudeCodeのBashOutputツールのために,標準出力にするか、unixserverのclientとして通信する(自動でタイムアウトしないとブロッキングしてAgent全体が止まるの注意)かが良い.
